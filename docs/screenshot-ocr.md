# 截图 OCR 与剪贴板翻译指南

LinguaDock V1.0.4 提供两条“复制不到文字时也能快速翻译”的路径：显式粘贴和截图 OCR。两者都会把取得的文字放入原文框，再沿用当前的智能、离线或在线翻译路线生成简中、英语、日语和繁中结果。

## 最快用法

### 粘贴并翻译

1. 在任意应用中复制文字。
2. 按 `Ctrl + Alt + G` 唤出译栈。
3. 点击“自动识别”右侧的剪贴板图标。
4. 译栈会读取当前文本剪贴板、填入原文并立即翻译。

这个按钮与“唤出时读取剪贴板”是两项独立功能：按钮只在用户主动点击时读取；自动读取默认关闭，可在“设置 → 通用”开启。

### 截图并翻译

1. 按 `Ctrl + Alt + S`，也可以点击输入区的截图图标或托盘菜单“截图翻译”。
2. 拖动框选含文字的区域。
3. OCR 完成后主窗口自动恢复，识别文字会进入原文框并立即翻译。
4. 内置截图界面可按 `Esc`、单击鼠标右键或再次触发截图快捷键取消。

截图快捷键可在“设置 → 通用 → 截图翻译快捷键”录制。规则与窗口快捷键相同：至少 2 个、最多 5 个按键，必须包含修饰键与一个普通键；两个全局快捷键不能相同。

## OCR 引擎

在“设置 → 通用 → 截图 OCR”可以选择：

| 选项 | 行为 | 适用情况 |
| --- | --- | --- |
| 自动推荐 | 检测到 PixPin 时优先使用 PixPin，否则使用 Windows 本地 OCR | 推荐默认值；无需反复切换 |
| PixPin OCR | 调用本机 PixPin 的公开脚本，框选后从剪贴板读取识别文字 | 已经安装并习惯 PixPin 的用户 |
| Windows 本地 OCR | 使用 LinguaDock 内置框选层、XCap 截图和 Windows.Media.Ocr | 不安装额外 OCR 软件；图片不上传 |

设置页会显示当前检测到的 PixPin 状态及 Windows OCR 语言列表。

## PixPin 接入方式

LinguaDock 使用 PixPin 官方文档公开的 Windows 启动命令：

```text
pixpin.exe -r "pixpin.screenShot(ShotAction.CopyOcrText)"
```

该动作让 PixPin 打开区域截图并把 OCR 文字复制到剪贴板。LinguaDock 记录调用前的 Windows 剪贴板序列号，只有检测到新的剪贴板内容后才继续翻译，避免把旧文字误当成 OCR 结果。

- 如果 PixPin 安装在常见目录，LinguaDock 可以检测并在需要时启动它。
- 如果 PixPin 安装在自定义目录，请先启动 PixPin；LinguaDock 会从运行进程取得实际路径。
- 等待 OCR 时再次触发译栈截图快捷键会结束 LinguaDock 的等待；PixPin 自身的框选层也可以按 `Esc` 取消。
- PixPin 是独立的第三方软件，没有捆绑进 LinguaDock；其 OCR 网络行为、账号与许可由 PixPin 自身设置和条款决定。

参考：[PixPin 官方脚本文档](https://pixpin.cn/docs/configuration/script)。

## Windows 本地 OCR

内置路径按显示器分别抓取物理像素画面，再在每个显示器上创建独立无边框框选层，因此能正确处理负坐标、多显示器和不同缩放比例。一次框选限定在一个显示器内，不能跨屏拖出一个选区。

- 手动指定原文为简中、英语、日语或繁中时，只请求对应的 Windows OCR 语言。
- 使用“自动识别”时，会尝试系统首选识别器及已安装的四种目标语言，从非空结果中按可见字符、文字比例和乱码惩罚择优。
- 小选区会适度放大，超大选区会限制长边，兼顾识别率与内存占用。
- Windows OCR 的准确率取决于系统语言包、字体清晰度、字号、对比度和图片压缩质量。

如果设置页提示语言包不可用，可在 Windows“设置 → 时间和语言 → 语言和区域”添加目标语言及其语言功能；管理员也可以按微软的系统能力方式安装，例如英语 OCR：

```powershell
Add-WindowsCapability -Online -Name "Language.OCR~~~en-US~0.0.1.0"
```

简体中文、日语和繁体中文使用对应的系统语言标记。安装后重新打开 LinguaDock，再到设置页检查检测结果。

## 隐私与临时文件

Windows 本地 OCR 路径不会上传截图：

1. 整屏画面先保存在 LinguaDock 进程内存中。
2. 用户选区被裁剪后写入系统临时目录中的随机 PNG，仅供 Windows OCR 读取。
3. 无论识别成功或失败，临时 PNG 都由清理守卫立即删除。
4. LinguaDock 不保存截图历史，也不把截图写入翻译历史。

OCR 结束后得到的是文字。文字是否发送到网络，取决于当前翻译设置：仅离线不会联网；Google 或 AI API 路线会把识别文字发送到对应服务。项目没有自己的中转服务器。

PixPin 模式下，截图由 PixPin 处理，LinguaDock 只读取它写入剪贴板的识别文字。

## 常见问题

### 截图后没有识别到文字

- 尽量只框选正文，减少图标、边框和复杂背景。
- 放大页面后重试；过小、模糊或艺术字体更难识别。
- 手动指定正确的原文语言，避免自动候选判断错误。
- 在设置页确认相应 Windows OCR 语言存在，或切换到 PixPin。

### 快捷键没有反应

快捷键可能被输入法、截图软件或录屏工具占用。在“设置 → 通用”录制另一组 2–5 键组合；注册失败时译栈会保留原快捷键并显示原因。

### 自动模式没有找到自定义目录里的 PixPin

先手动启动 PixPin，再刷新或重开译栈设置页。运行中的 PixPin 可以从进程取得路径，不要求安装在默认目录。

### 框选层位置或尺寸不正确

先确认 Windows 的显示缩放设置已经应用，然后重启译栈。不同缩放比例的显示器会使用各自的选区窗口；请在单个屏幕内完成一次框选。
