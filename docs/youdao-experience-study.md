# V1.0.3–V1.0.4：网易有道翻译桌面体验研究

调研日期：2026-09-19。目标不是制作网易产品的像素级复制品，而是提炼一个桌面翻译工具真正高频、低摩擦的工作流，再用 LinguaDock 自己的品牌、布局和代码独立实现。

## 调研范围

本次调研使用了三类只读信息：

1. 网易有道公开的桌面词典帮助页，例如 [桌面版帮助入口](https://cidian.youdao.com/help5.html) 和 [OCR 取词说明](https://cidian.youdao.com/5.0/help/deskdict5beta/features/06.html)。
2. 开发机已安装的网易有道翻译 11.3.22.0 的可见功能入口、进程名称、资源目录结构和布局资源文件名。
3. 用户目录中已经下载的离线词典与 NMT 模型文件的名称、大小和文件头；没有读取、反编译或提取词典正文。

公开帮助页偏旧，因此“当前桌面版有哪些入口”的判断主要来自 11.3.22.0 的本机安装结构；这部分属于工程观察，不代表网易官方对产品能力的最新承诺。

## 高频体验拆解

| 工作流 | 有道桌面版观察 | LinguaDock 当前实现 | 状态 |
| --- | --- | --- | --- |
| 快速唤出 | 全局入口、迷你窗口、托盘驻留 | 全局快捷键显示 / 隐藏，托盘驻留，默认置顶 | 已完成 |
| 输入与翻译 | 主输入区、查词与整句翻译 | 一次输入，简中 / 英 / 日 / 繁中四语同屏 | 已完成 |
| 单词深查 | 词性、多义项、例句、发音 | 词性、多义项、简短例句、系统朗读、本地词库补充 | 已完成核心能力 |
| 结果复用 | 复制、单词本、历史 | 单卡复制、全部复制、收藏、可关闭本地历史 | 已完成 |
| 离线能力 | 多部增强词典、发音包、NMT 模型 | 内置基础词典、OpenCC、本地服务、本地模型、开放词库导入 | 已完成安全兼容路径 |
| 剪贴板工作流 | 剪贴板查词 / 划词相关入口 | 显式粘贴并翻译；可选“唤出时读取剪贴板” | V1.0.4 完成 |
| 截图翻译 | 截图、OCR、复制、保存等入口 | PixPin / Windows OCR、全局快捷键、多屏框选、识别后四语翻译 | V1.0.4 完成核心能力 |
| 划词 / 屏幕取词 | 取词、划词、OCR 强力取词 | 尚未实现 | 需要 Windows 辅助功能、Hook 与权限设计 |
| 文档翻译 | 文档翻译入口 | 尚未实现 | 需要格式保真、分页、文件隐私与失败恢复 |
| AI 辅助 | AIBox、语法或写作类入口 | 四语 AI 翻译、四种风格、多服务商 | 已完成翻译主线，不扩张为内容平台 |

项目的原则是：能可靠工作的入口才显示。V1.0.4 在真实屏幕捕获与 Windows OCR 验证通过后才加入截图入口；划词和文档翻译仍不会先做无法完成任务的按钮。

## 界面结论

有道完整桌面产品承担了词典、翻译、学习、写作和账号商业化等多种任务，功能密度较高。LinguaDock 不复制它的导航、颜色、图标、文案或品牌资产，而采用两层结构：

- 标题栏只保留品牌、设置、主题、置顶和隐藏。
- 主区只保留“翻译 / 词库 / 收藏 / 历史”四个高频入口。
- 翻译页坚持一次输入和四语同屏；不会用多层目标语言选择打断操作。
- 高级引擎、密钥、快捷键和隐私选项都收进设置页。

这使窗口既能承担“像桌面词典一样随叫随到”的任务，又不会变成课程、资讯、会员和营销入口的集合。

## 本机离线资源观察

网易有道翻译的用户资源通常位于：

```text
%LOCALAPPDATA%\Yodao\DeskDict\Dictionary
%LOCALAPPDATA%\Yodao\DeskDict\nmt_model
```

开发机上观察到以下类型：

| 类型 | 示例 | 判断 | LinguaDock 行为 |
| --- | --- | --- | --- |
| 商业词典包 | `collins.dat`、`oxford_advance.dat`、`hy.dat` | 自定义二进制格式，可能包含第三方授权内容 | 只显示文件名与大小，不读取正文 |
| 发音包 | `voiceUK.dat`、`voiceUS.dat` | 自定义二进制语音资源 | 不导入、不重新分发 |
| 本地词典数据库 | `dicten.db`、`dictja.db` 等 | 文件头不是 SQLite，属于专有封装 | 不尝试绕过格式 |
| NMT 模型 | `model.npz`、词表与 codec 文件 | 旧式神经翻译模型组合，运行时与授权均不明确 | 只检测，不加载 |
| 模型压缩包 | `cj_nmt.7z` | 封装资源 | 不自动解压或复制 |
| 个人单词本导出 | XML | 用户自己导出的结构化数据 | 支持从“词库”页导入 |

“文件在本机”不等于“有权将其抽取并放进另一个开源软件”。LinguaDock 不提供解密、破解、格式绕过或重新分发逻辑。资源检测命令是只读的，也不会修改网易有道翻译的任何文件。

## 可合法迁移的数据

LinguaDock 支持用户自己拥有或有权使用的开放数据：CSV、TSV、JSON、XML、TXT、未压缩 StarDict，以及从有道导出的个人单词本 XML。详细格式见 [词库导入指南](dictionary-import.md)。

如果某部词典拥有独立开放许可，应从该词典的官方发布渠道取得开放版本，再转换为受支持格式；不要直接复制商业客户端的 `.dat` 或 `.db` 文件。

## 独立实现与商标边界

- LinguaDock 没有复制网易有道翻译的源码、布局文件内容、图标、截图或词典正文。
- “网易”“有道”及其产品名和标识属于相应权利人；项目中的名称仅用于兼容性说明。
- LinguaDock 与网易有道没有隶属、赞助或合作关系。
- 借鉴范围限于不受垄断的通用工作流：快捷唤出、查词、翻译、朗读、收藏和历史。
